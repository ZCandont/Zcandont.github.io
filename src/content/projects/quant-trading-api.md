## Spotted

Overarching goal: create a model to passively trade stocks at a high profit.

## Root cause

Assumptions:

- Current models can be improved upon and are missing something that can be taken advantage of.
- Stocks react like nature, but the natural responses are to "super"natural decisions.
- The market is the "weak" form of market analysis, therefore there must be a "strong" form.
- Market data can be shaped into a mesh, so it can be reshaped into a continuous solution, optimized, and extrapolated.

## Plan

Subgoals:

- A dashboard for aligning agent strategies, connecting to markets to make trades, and highlighting key data.
- An agent that can model stock behavior over time.
- An agent that performs historic backtesting on stock data and supervised learning on future stock performance.
- An agent that makes real-time trade assessments within milliseconds of new data or seconds of news.
- Large datasets compressed into variables for quicker model assessment and training.
- Stocks assessed as geometric figures using FEM.
- Topological optimization on stocks to assess the resulting "deflection" from "loads" and "boundary conditions."

The main goal is optimization:

| Minimize | Maximize |
|---|---|
| Number of trades | Profit |
| Time to profitability | Availability of data |
| Taxable gains | Multi-strategy use and judgment of strategy choice |
| Data input | Natural and swarm intelligence modeling |
